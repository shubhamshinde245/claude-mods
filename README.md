# claude-mods

Claude Code mods by Shubham Shinde.

```
/plugin marketplace add shubhamshinde245/claude-mods
```

| Mod | What it does |
| --- | --- |
| [usage-meter](plugins/usage-meter) | Plan limits, time-to-limit pace, session cost, tokens, cache hit rate, context and model in the band above the prompt |

Install one with `/plugin install <mod>@shubham-mods`.
